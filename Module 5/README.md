# Library Aid Africa - Library Data Analysis & Management Course

## Module 5: 7th October 2026

### Data Analysis with DAX in Power BI
This module introduces learners to DAX (Data Analysis Expressions) in Power BI for creating calculated columns, measures, and custom business logic to support library performance analysis and decision-making. It builds on earlier data modelling lessons by showing how to turn raw library data into meaningful indicators for circulation, fines, service usage, and operational monitoring.

#### DAX in Power BI
The lesson introduces learners to the process of:
- creating calculated columns and measures
- using DAX functions for aggregation, filtering, and comparison
- understanding context and evaluation in Power BI calculations
- building KPIs for library performance reporting
- applying DAX to support evidence-based decision making

#### Learning Focus
This module helps learners to:
- transform raw data into analytical insights
- build meaningful measures for library operations
- improve dashboard accuracy and reporting quality
- support strategic decision making in library management
