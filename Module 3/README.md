# Library Aid Africa - Library Data Analysis & Management Course

## Module 3: 2nd September 2026

### Data Modelling and Relationships in Business Intelligence
This module builds on the foundations of Power BI by introducing learners to the importance of data modelling and relationships in creating reliable and insightful dashboards. It helps participants understand how data from different tables can be connected and used to answer library management questions effectively.

#### Data Modelling and Relationships in Power BI
The lesson introduces learners to the process of:
- creating and managing relationships between tables
- understanding fact and dimension tables
- identifying primary and foreign keys
- applying cardinality and filter direction
- building a data model for effective reporting
- using connected tables to generate business-ready insights

#### Learning Focus
This module helps learners to:
- structure data for analytical use
- connect multiple datasets thoughtfully
- improve dashboard accuracy and reporting quality
- support evidence-based decision making in library operations
