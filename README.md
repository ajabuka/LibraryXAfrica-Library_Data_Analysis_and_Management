# Library Aid Africa - Library Data Analysis & Management Course

## First Cohort: August 2026 - July 2027


Welcome to the repository of the [Library Data Analysis & Management Course](https://lxa.libraryaidafrica.org/courses/library-data-analysis-management/). Here you will 
find all materials relating to the Course.

## Blurb
This course equips librarians with practical skills to collect, clean, manage, and analyze library data for planning and library service improvement. By the end of the course, librarians will be able to manage library data more effectively and use it to improve library services and demonstrate impact.

**Teaching Format**: The classes will span for 6 months, scheduled to hold once in 2 weeks. Capstone Project or Library Internship for another 6 months with monthly check-ins

**Facilitator**: [Jesubukade Ajakaye](https://www.linkedin.com/in/jesubukade-ajakaye/)

Work in progress: This repository is under construction and details will continue to be added through the Course.
